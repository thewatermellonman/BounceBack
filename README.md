# Slime Catcher

A game where you play as a princess trying to catch the slimes that are running over her kingdom. 

## Gameplay
- Use the left and right arrows to move around. The character cannot jump, she can only go up when on a bounce pad. 
- Once you reach the final boss, the hearts in the corner are the bosses hearts.


## Known Issues
- Sometimes there are issues with acciedentally getting reset on stage 4 (the one with the hole in the ground)
- There are also bugs with jump height on some computers. 

This game was made in Godot.
